# 拾光小盒 · 内容工作室

## 改动总览

内容工作室从本地 HTML 原型接入了 Node 管理服务。游戏页面提供「管理员入口」，也可直接访问 `/studio.html`；登录后按五步引导整理故事与礼物，并把完整内容保存到默认三消游戏。开发环境使用 `npm run dev`，生产环境使用 `npm run build && npm start`。

管理员密钥位于 `config/admin.json` 的 `adminKey`，初始值为 `whoops2026`。校验在服务端完成；正式部署更换密钥后需重启服务。纯静态托管与 `npm run preview` 没有管理 API，不能登录或保存，只运行构建时的默认故事。

## 流程与视觉

采用五步引导：送给谁、六段回忆、写一封信、准备礼物、检查预览。分步填写减少首次准备素材的负担，同时保留随时返回修改和核对六段回忆的能力。

沿用游戏的纸色 `#f7f3e9`、暖棕 `#a5654e`、墨色 `#514d40`，标题使用宋体，正文使用中文无衬线。左侧为导航与准备进度，中间为编辑区，右侧为实时内容预览；窄屏改为横向步骤与按需预览。复用项目原创回忆与礼物 SVG，不引入外部图片、字体或依赖。

## 字段与引导

- 送给谁：昵称、署名、场景、日期、开场标题和一句话。没有本地草稿或已发布内容时为空白草稿，可主动载入标明虚构的示例。
- 六段回忆：保留现有六个 ID，每段支持标题、日期、正文、图片、替代文字。用「当时发生了什么」「最记得哪个细节」等问题引导，图片可沿用默认插画。
- 信件：以段落编辑，提供可选开头句与模板；已有文字被示例覆盖前必须确认。
- 礼物：礼物类型、名称、说明、图片、领取方式、有效期；可选小鹅彩蛋。
- 检查预览：列出缺少的必填内容并直达对应步骤；完整预览按封面、六段回忆、信、礼物播放。补齐内容后可「保存到游戏」，发布前确认将替换玩家读取的故事。

## 本地草稿与发布

| 操作 | 数据位置 | 对游戏的影响 |
| --- | --- | --- |
| 输入后自动保存 | 当前浏览器的独立 IndexedDB | 不影响已发布内容 |
| 导出草稿备份 | 下载 JSON，包含文字与内嵌图片 | 不发布，可导入继续编辑 |
| 保存到游戏 | 服务端 `.data/content.json` | 所有玩家重新打开或刷新默认三消后生效 |
| 载入游戏当前内容 | 用服务端内容替换本地草稿，操作前确认 | 不修改服务端内容 |

登录后优先恢复本地草稿；没有本地草稿时读取已发布内容。草稿不会读写游戏进度。自动保存异常时保留内存编辑并提示导出备份；退出管理保留本地草稿，更换浏览器、域名或清理站点数据不会迁移它。

图片限 JPG、PNG、WebP，单张不超过 3 MB；解码校验后作为 data URL 保存，导出 JSON 包含图片，不依赖本地绝对路径。导出格式为 `memory-arcade-studio`、版本 `1`，包含基础信息、六段回忆、信件、礼物和可选彩蛋。未完成的草稿也可导出备份。

导入验证格式、版本、字段类型、长度、六个固定 ID、图片协议与体积；覆盖草稿需确认，取消保留当前数据。「保存到游戏」还会在服务端再次校验完整性，成功后原子替换已发布文件，不清空玩家进度。已有进度按原有顺序解锁回忆，发布时应核对故事对应关系。旧版平台闯关继续使用源码内置故事。

## 服务与数据边界

- `config/admin.json` 仅由服务端读取。登录会话使用 HttpOnly cookie，有效期 8 小时；退出或服务重启后失效。
- `.data/content.json` 不入 Git，更新部署需保留并定期备份；容器部署挂载持久化目录。可恢复文件，或导入 JSON 后重新保存到游戏。
- 默认 `PORT=3000`、`HOST=0.0.0.0`、`BASE_PATH=/`。子目录部署需让构建和启动使用相同 `BASE_PATH`，管理员路径也带此前缀。完整部署步骤见 [发布说明](../RELEASING.md)。
- 管理页面与 API 不进入 Service Worker 离线缓存；登录、发布与读取已发布故事需要联网。当前服务采用单实例、内存会话，无数据库。
- 管理员登录只限制修改权限。玩家可以直接读取公开内容 API 和前端素材，关卡解锁与本地进度都不是保密边界，不能将游戏用作秘密保险箱。

## 通关邮件卡片

玩家完成最后一关、读信并拆开礼物后，礼物页自动生成邮件形式的卡片，呈现收件人、赠送者署名、信件和礼物。卡片可直接预览，也可下载为 `memory-arcade-letter.html`；图片可用时一并嵌入，加载失败时仍可下载文字版。小鹅彩蛋揭晓后可随卡片保存。

这项能力只生成预览与本地下载，不收集邮箱、不发送邮件，不需要 SMTP 配置。导出的卡片包含个人故事，应按私人素材保管。

## 验收重点

- 登录：错误密钥被拒绝，正确密钥进入工作室，过期或退出后重新登录；纯静态环境明确提示服务不可用。
- 编辑：步骤切换、实时预览、示例、导入导出、刷新恢复、图片选择和窄屏布局正常；覆盖草稿前有确认。
- 发布：未完整内容不能保存；本地编辑不改变游戏；保存成功后另一浏览器可读到新内容，重启服务后内容保留。
- 通关：默认游戏玩法与进度正常，礼物页生成邮件卡片，下载 HTML 可打开阅读，图片失败时有文字版提示。
- 边界：管理员密钥与 `.data/` 不由静态服务器公开；不将通关状态描述为真实兑换凭据或身份认证。
